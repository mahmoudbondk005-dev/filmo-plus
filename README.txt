فيلمو — نسخة محسّنة (مجانية بدون اشتراكات)

1) افتح index.html لمعاينة الموقع.
2) admin.html واجهة إدارة (كلمة المرور: Filmo2026).
3) الميزات الجديدة:
   - مفضلة محلية (♥ على كل بطاقة + زر في صفحة التفاصيل)
   - سجل مشاهدة أخير (آخر 24 عمل)
   - بحث فوري أثناء الكتابة (اسم + وصف)
   - رسائل toast أوضح
   - تحسين رسائل خطأ المشغل
   - حماية لوحة التحكم بكلمة مرور مشفّرة (SHA-256) بدل النص الواضح
4) للإطلاق الحقيقي: دومين + استضافة + HTTPS + تفعيل RLS على Supabase.
5) لا تضع روابط أو ملفات أفلام محمية إلا إذا كنت تملك ترخيص عرضها.
6) الإعلانات وAdSense تُضاف بعد تجهيز الموقع القانوني.
