سيما سيما
موقع أفلام ومسلسلات عربي/أجنبي.

ملفات المشروع:
- index.html: واجهة المستخدم والمشغل وصفحات المحتوى داخل التطبيق.
- admin.html: لوحة التحكم.
- _worker.js: طبقة Cloudflare Pages لتحويل روابط /movie/... و /series/... إلى صفحات قابلة للقراءة لمحركات البحث، وإنشاء sitemap.xml ديناميكيًا من Supabase.
- setup-downloads.sql: إضافة عمود روابط التحميل المتعددة إلى Supabase.
- setup-security.sql: حماية جدول المحتوى حسب الصلاحيات.
- setup-views.sql: تفعيل عداد المشاهدات (قسم الأكثر مشاهدة).

SEO:
- لكل فيلم رابط ثابت بالشكل /movie/اسم-الفيلم~ID.
- لكل مسلسل رابط ثابت بالشكل /series/اسم-المسلسل~ID.
- _worker.js يضيف عنوان ووصف وصورة وCanonical وSchema.org تلقائيًا للصفحة المطلوبة.
- /sitemap.xml يتم توليده تلقائيًا من محتوى جدول movies.
- لا تحتاج لإعادة إنشاء sitemap يدويًا عند إضافة عمل جديد، بشرط نشر المشروع عبر Cloudflare Pages مع دعم _worker.js.

لوحة التحكم:
- تسجيل الدخول يتم عبر Supabase Auth. لا يتم تخزين كلمة مرور الإدارة داخل ملفات الموقع.
- روابط المشاهدة والتحميل الموجودة في قاعدة البيانات لا يتم تغييرها بواسطة طبقة SEO.
- روابط التحميل: يمكن إضافة سيرفر واحد أو عدة سيرفرات لكل محتوى.
- علامة سيما سيما على الفيديو: يمكن تفعيلها وتحديد مكانها لكل محتوى.
- مفتاح TMDB يُدخل من لوحة التحكم ويُحفظ في المتصفح.

مهم للنشر:
- المشروع مصمم لـ Cloudflare Pages Advanced Mode لأن _worker.js يجب أن يعمل كـ Worker فعلي.
- إذا كنت تستخدم GitHub مع Cloudflare Pages، ارفع ملفات المشروع في جذر المستودع، وتأكد أن إعدادات النشر تستخدم المجلد الذي يحتوي على _worker.js وملفات الموقع.
- إذا كانت قاعدة البيانات تستخدم عمود Id بدل id فالكود يدعم الاثنين.


تحديثات SEO الأخيرة:
- _worker.js فيه إعدادات في أعلى الملف:
  INDEX_EPISODES = false  -> صفحات الحلقات noindex,follow وغير موجودة في sitemap (تفهرس صفحة المسلسل فقط). غيّرها إلى true لفهرسة الحلقات.
  SITEMAP_CHUNK = 10000   -> /sitemap.xml أصبح فهرس sitemap يشير إلى /sitemap-1.xml و /sitemap-2.xml ... (الحد الأقصى لكل ملف 50000 رابط).
  HOME_LATEST = 48        -> عدد روابط أحدث الأعمال المحقونة في الصفحة الرئيسية.
- الصفحات المولدة والـ sitemap تُخزّن على حافة Cloudflare (Cache API) لمدة 5-10 دقائق، فأي تعديل في لوحة التحكم قد يظهر بعد دقائق.
- لو Supabase غير متاح مؤقتًا، صفحات الأفلام/المسلسلات/الحلقات ترجع 503 مع Retry-After (بدل 200 بلا SEO أو 404).
- روابط الحلقات في صفحة المسلسل صارت ظاهرة للمستخدم (بدل عنصر مخفي 1px).
